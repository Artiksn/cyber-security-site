# 🛡️ КиберЩит — сайт с советами по кибербезопасности

Стильный одностраничный сайт на чистом **HTML + CSS + JS** — без сборки, фреймворков и зависимостей:

- 9 базовых привычек цифровой безопасности
- 6 признаков фишингового письма и что делать
- интерактивный чек-лист (прогресс сохраняется в браузере)
- генератор надёжных паролей (всё считается локально через криптографический ГСЧ, на сервер ничего не уходит)
- FAQ-аккордеон
- тёмная «кибер»-тема: неоновые акценты, анимированный фон из частиц, адаптивность под телефон

Структура проекта:

```
index.html   — разметка страницы
styles.css   — стили (тёмная тема, анимации, адаптивность)
script.js    — интерактив: частицы, печатающийся заголовок, чек-лист, генератор, FAQ
README.md    — этот файл
```

## Запуск локально

Просто открой `index.html` двойным кликом — всё работает без сервера.
Или через локальный сервер:

```bash
python -m http.server 8080
# → открой http://localhost:8080
```

## 🚀 Как развернуть на GitHub Pages

GitHub Pages — бесплатный хостинг для статических сайтов. После деплоя сайт получит адрес вида:

```
https://<твой-логин>.github.io/cyber-security-site/
```

### Способ 1. Через веб-интерфейс (без командной строки)

1. Зарегистрируйся на [github.com](https://github.com) (если ещё нет аккаунта).
2. Нажми **«+»** в правом верхнем углу → **New repository**.
3. Назови репозиторий `cyber-security-site`, выбери тип **Public** → **Create repository**.
4. На странице репозитория нажми ссылку **«uploading an existing file»** (в блоке Quick setup).
5. Перетащи в окно файлы `index.html`, `styles.css`, `script.js` (можно и README.md), внизу нажми **Commit changes**.
6. Открой вкладку **Settings** → слева в меню **Pages**.
7. В блоке **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка: **/ (root)**
   - Нажми **Save**
8. Подожди 1–2 минуты и обнови страницу — сверху появится адрес сайта (или нажми **Visit site**):

   `https://<твой-логин>.github.io/cyber-security-site/`

Готово! Эта ссылка работает из любой точки мира, её можно отправлять кому угодно.

### Способ 2. Через git (командная строка)

```bash
# в папке с файлами сайта
git init
git add .
git commit -m "КиберЩит: первая версия"
git branch -M main
git remote add origin https://github.com/<твой-логин>/cyber-security-site.git
git push -u origin main
```

Дальше повтори шаги 6–8 из способа 1.

## Обновление сайта

- **Через веб:** открой нужный файл в репозитории → карандаш ✏️ → правь → **Commit changes**. Через минуту изменения появятся на сайте.
- **Через git:** `git add . && git commit -m "описание" && git push`.

## Полезно знать

- Репозиторий должен быть **Public** — Pages из приватного репозитория доступен только на платных тарифах GitHub.
- `index.html` должен лежать в **корне** репозитория (или в папке `docs/`, если выбрать её в настройках Pages).
- Первый деплой обычно занимает 1–5 минут, обновления — быстрее.
- Хочешь свой домен? Settings → Pages → Custom domain.
